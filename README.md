# 🎮 Pixel Run

## Über das Projekt

**Pixel Run** ist ein eigenes 2D-Plattformspiel, das ich mit **Python und Pygame** entwickelt habe.

Das Ziel des Spiels ist es, durch verschiedene Level zu kommen, Münzen zu sammeln, Gegner zu besiegen und am Ende den Boss zu besiegen.

Das Projekt habe ich selbst entwickelt, um meine Kenntnisse in Python und Spieleentwicklung zu verbessern.

---

## 🕹️ Funktionen

* 4 verschiedene Level
* 3 normale Level mit zunehmendem Schwierigkeitsgrad
* Boss Fight im 4. Level
* Bewegung nach links und rechts
* Doppelsprung
* verschiedene Gegner
* Münzen und Punktesystem
* Kollisionserkennung
* Leben-System
* Game Over
* Neustart des Spiels
* Animationen
* Boss mit Lebenspunkten
* Boss-Projektile
* verschiedene Plattformen und Level-Layouts

---

## 🎯 Level

### Level 1 – EASY

Breite Plattformen und kleinere Abstände. Ideal zum Kennenlernen der Steuerung.

### Level 2 – MEDIUM

Kleinere Plattformen, größere Abstände und anspruchsvollere Sprünge.

### Level 3 – HARD

Schmale Plattformen und längere Sprünge. Präzise Bewegungen sind notwendig.

### Level 4 – BOSS FIGHT

Ein Boss mit Lebenspunkten und Projektilen. Der Boss muss mehrmals getroffen werden, um das Level zu gewinnen.

## ▶️ Installation und Start

### 1. Repository herunterladen

Repository klonen oder als ZIP herunterladen.

### 2. Abhängigkeiten installieren

```bash
pip install -r requirements.txt
```

### 3. Spiel starten

```bash
python main.py
```

## 🧪 Tests

Für die Level-Logik habe ich automatische Tests erstellt.

Die Tests überprüfen unter anderem:

* korrekte Münzplatzierung
* Plattformen innerhalb des Spielfelds
* Gegnerplatzierung
* Gegnergeschwindigkeit
* Boss-Level ohne normale Gegner
* korrekte Level-Struktur

Tests starten mit:

```bash
python -m unittest discover -s tests -v
```
